# bateri Homebrew tap

Install [bateri](https://bateri.dev), a GPU-drawn terminal for macOS:

```
brew install bateri/tap/bateri
```

The cask always downloads the latest release from
[bateri/bateri](https://github.com/bateri/bateri/releases/latest). Once
installed, bateri updates itself.

Requires macOS 14 or later on Apple silicon.
